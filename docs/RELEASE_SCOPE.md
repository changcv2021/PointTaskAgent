# 保留与排除

## 必须保留

1. `src/agent.py` / `run_selected.py`：实际的代码生成、执行反馈、改写和终止逻辑。
2. `kernel.py` / `kernel_worker.py`：每例持久 Python 作用域、超时、文件与网络隔离。
3. `scene_api.py` / `diagnostics.py` / `diagnostic_trace.py`：真实点索引、几何测量、候选比较和证据追踪。
4. `visualization.py` / `renderer.py`：模型实际观察的真实点云视图，附原始点 ID 与哈希。
5. `paid_api.py`：Responses 请求、high 推理配置、共享预算账本、失败费用保留与缓存。
6. 四类候选：TRACK_TO_DET、SEG_TO_DET、DET_TO_SEG、TRACK_TO_SEG。
   当前 coding 实验只允许已有检测框的中心修改及完整的既有分割 patch；不允许任意新框或任意标签编辑。
7. `evaluate_selected.py` / `official_metrics.py` / `geometry.py`：四项指标和离线有益/有害/最优选择判断。
8. 冻结选样、配置、提示词、候选来源协议、基线模型配置和源码提交号。
9. 原实验实际使用过的截断恢复与 pilot 最终决策脚本；恢复也受累计 5 次代码尝试和同一预算约束。
10. 完整统计与可展示案例，避免只公开正面结果而丢失总体分母。

## 未放入

- RL/SFT 训练代码、旧动作控制器和旧模型服务。
- 已取消的 SAFDNet，以及与这次 coding 主实验无关的模型横向对比。
- Flow/TEMPORAL 工具在当前运行入口中的功能；它们不在本次选样候选集合内。
- 旧实验全部日志、请求/响应原文备份、排队控制器、失败调试副本和视频生成历史。
- 数据集、预测 NPZ、大型点云、模型权重、Conda/pip 缓存、编译产物和 API 密钥。

`reproduction/upstream/` 是少量必要的**历史来源文件**，不是当前推理入口。
共享文件可能保留未调用的 Flow、ADD_BOX 或旧状态更新分支，用于说明冻结缓存的来源。
这些分支不导入 `src/`，也不属于本次方法使用范围。后续完善端到端复现时，可以进一步
拆分来源文件；当前保留完整函数上下文，避免错误地删除曾参与缓存准备的依赖。

## 这次整理做了哪些改动

- 运行目录改由 `PTA_RUN_DIR` 指定，API 地址/密钥改由环境变量指定；没有复制真实凭据。
- 提取当前用到的渲染函数，移除对旧实验 runtime 的导入；保留 SeeGround 许可证。
- 官方检测评测只提取当前调用的函数，移除未使用的旧 DeepSeek 全量评测 main。
- 沙箱通过显式软件挂载配置运行；没有无隔离模式。
- 历史 API 预检收据路径改为本机离线依赖检查收据；实际响应仍验证返回模型及 high 配置。
- 原始算法、提示词、选择规则、最多 5 次代码尝试和预算账本逻辑保持原意。
- `SOURCE_MANIFEST.json` 逐项记录来源哈希与改动，打包文件哈希在 `FILE_MANIFEST.json`。

## 后续仍需完善

这是从已整理和检查的源码准备包导出的公开仓库。项目主代码许可证尚未由作者选择。
完整数据到候选的上游脚本仍使用路径占位符；需在新机器配置并实际跑通基线与准备流程。
模型 checkpoint 的来源、校验值及可获取方式也应随最终论文版本一起固定。
使用 `validation/` 的实测范围描述验证，不把两个记录案例的代码回放称作重新运行 100 例模型实验。
